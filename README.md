# heap-mapper

`heap-mapper` — прототип модуля генерации тестовых данных для динамических
структур C на основе метода отображения адресов.

Проект строит псевдо-адресную модель входной структуры по заданному пути
выполнения и генерирует C-код для воспроизведения этого входа.

## Возможности MVP

- чтение пути выполнения из JSON;
- построение связей между узлами через псевдо-адреса;
- поддержка `NULL`, равенства и неравенства указателей;
- ограничение числовых полей, например `x.key == 5`;
- обнаружение неосуществимых путей;
- генерация C harness для структуры `Node`.

## Пример запуска

```bash
python -m heap_mapper examples/singly_list.json --out generated/test.c
```

Для неосуществимого пути:

```bash
python -m heap_mapper examples/infeasible_path.json --out generated/bad.c
```
